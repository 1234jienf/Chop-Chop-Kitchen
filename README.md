# Chop-Chop Kitchen

> 목소리로 칼질하고 불을 조절하며, 세 명의 셰프가 한 코스를 이어 완성하는 3인 협동 쿠킹 릴레이 웹게임

Chop-Chop Kitchen은 1인칭 주방에서 세 플레이어가 조리 공정을 차례로 수행하는 브라우저 게임입니다. 플레이어는 버튼을 반복해서 누르는 대신 “탁”, “후우~”, “보글보글”, 특정 음정 등의 소리를 마이크에 입력해 재료를 자르고, 굽고, 끓이고, 섞고, 마무리합니다.

하루의 4코스를 모두 완성하면 공정별 정확도를 바탕으로 코스 점수, 별점과 매출이 계산됩니다. AI는 계산된 결과를 손님의 자연스러운 미식 리뷰로 표현하며 게임 점수 자체에는 관여하지 않습니다.

## 핵심 특징

- 세 명이 한 공정씩 이어받는 실시간 협동 릴레이
- 마이크 음량, 음성 리듬, 발화 내용과 음높이를 활용한 조리 미니게임
- 자르기 결과가 이후 굽기 재료의 조각 수에 반영되는 공정 연결
- 손님 취향에 따른 목표 공정과 달성 보너스
- 고정 공식으로 계산되는 코스 점수, 1~5성 평가와 매출
- 결과 데이터를 미식 언어로 바꾸는 선택형 AI 손님 리뷰
- 데스크톱과 모바일 화면을 고려한 웹 UI

## 게임 흐름

```text
식당 입장
  → 셰프 3명 방 참가
  → 카드 드래그로 릴레이 순서 결정
  → 4코스 순차 조리
  → 코스 완료 연출
  → 손님 리뷰 및 매출 정산
  → 다음 날
```

## 게임 방법

### 목표

세 명의 플레이어가 정해진 차례에 맞춰 모든 조리 공정을 완료하고 높은 정확도를 기록하는 것이 목표입니다. 오늘의 손님이 선호하는 종류의 공정을 모두 70점 이상으로 완료하면 최종 점수 5점과 매출 100G를 추가로 받습니다.

### 시작하기

1. **게임 시작**을 누르고 식당으로 들어갑니다.
2. 세 플레이어가 같은 방 코드와 각자의 이름을 입력합니다.
3. 각자 **방 참가**를 누릅니다.
4. 플레이어 카드를 드래그해 릴레이 순서를 정합니다.
5. 세 명 모두 **준비하고 시작하기**를 누르면 게임이 자동으로 시작됩니다.
6. 현재 차례인 셰프만 마이크와 조리 입력을 사용할 수 있으며 나머지 셰프는 같은 장면을 관전합니다.

### 조작법

조리 화면에서 **마이크 켜기**를 누르고 브라우저의 마이크 권한을 허용합니다.

| 공정 | 입력 및 판정 방식 |
| --- | --- |
| 자르기 | 목표 리듬에 맞춰 “탁”, “찹”처럼 짧은 소리를 냅니다. 소리 한 번이 칼질 한 번으로 처리되며 타이밍과 간격을 평가합니다. |
| 굽기 | “후우~” 하는 음량으로 화력을 높이고, 소리를 줄여 화력을 낮춥니다. 변화하는 목표 화력 구간에 불 세기를 맞춥니다. |
| 끓이기 | “후우~”처럼 마이크에 일정한 소리를 내어 불을 키웁니다. 소리를 유지해 끓이기 진행도가 목표에 도달하면 공정이 완료됩니다. |
| 섞기 | 화면의 가이드 문장을 읽습니다. 음량과 인식 문장의 일치도가 섞는 움직임과 정확도에 반영됩니다. |
| 뿌리기·붓기 | “아—” 하고 소리를 길게 내 목표 음정에 도달한 뒤 정해진 시간 동안 유지합니다. |
| 오븐 굽기 | 돌아가는 다이얼을 확인하고 목표 시점에 “띵”이라고 말해 오븐을 멈춥니다. |

마이크를 사용할 수 없는 발표·테스트 환경을 위해 **성공 입력**, **실수 입력**, 화력 테스트 버튼도 제공합니다.

### 점수와 하루 종료

- 각 공정 정확도는 20~100점으로 제한됩니다.
- 코스 점수는 해당 코스 공정 점수의 평균입니다.
- 최종 점수는 네 코스의 평균에 손님 조건 보너스를 더해 계산합니다.
- 별점은 최종 점수 20점당 하나이며 최소 1개, 최대 5개입니다.
- 각 코스 매출은 `75 + 코스 점수 × 2`입니다.
- 손님 조건을 만족하면 최종 점수 `+5`, 매출 `+100G`를 받습니다.
- 네 코스의 모든 공정이 끝나면 손님 리뷰와 하루 정산 화면이 표시됩니다.
- **정산하고 다음 날**을 누르면 매출이 누적되고 새로운 손님과 다음 날을 시작합니다.
- 누적 자금이 3,000G 이상이면 식당 등급이 1성에서 2성으로 올라갑니다.

현재 데모에는 게임 오버나 최종 엔딩이 없습니다. 한 번의 플레이 사이클은 4코스 완료 후 하루 정산까지입니다.

### 공정별 평가 기준표

| 공정 | 주요 평가 요소 | 점수 산정 기준 |
| --- | --- | --- |
| 자르기 | 요구된 소리의 종류와 칼이 목표 지점을 지나는 타이밍 | 기본 40점에서 `PERFECT +12`, `GOOD +9`, `WRONG +5`, `EARLY·LATE +3`을 더하고 입력 실수마다 3점을 뺍니다. 일반 결과는 28~94점이며 모든 칼질이 `PERFECT`이면 96점입니다. |
| 굽기 | 전체 조리 시간 중 현재 화력이 목표 구간에 머문 비율 | 기본 20점에 목표 화력 유지 비율을 반영합니다. 전체 시간의 90% 이상을 목표 구간에서 유지하면 100점입니다. |
| 끓이기 | 바람 소리 등 일정 음량을 유지해 진행도를 채우는 데 걸린 시간 | 마이크 입력이 음량 기준을 넘거나 음성 모델이 `Huu` 등의 유효 소리를 감지하면 끓이기가 진행됩니다. 진행도를 13초 이내에 모두 채우면 100점이며 이후에는 초당 3점씩 감점합니다. 30초를 넘기면 20점입니다. |
| 섞기 | 화면의 가이드 문장과 인식된 발화의 일치율 | `20 + 문장 일치율 × 80`으로 계산합니다. 일치율 0%는 20점, 100%는 100점입니다. |
| 뿌리기·붓기 | 목표 음정 도달 시간과 음정 유지 성공 여부 | 목표 음정에 5초 이내 도달하면 100점입니다. 이후에는 1초마다 5점씩 감점하며 최저점은 20점입니다. 여러 목표 음이 있으면 각 단계 점수의 평균을 사용합니다. |
| 오븐 굽기 | “띵”으로 오븐을 멈춘 시점과 목표 시점의 차이 | 오차가 0.25초 이하면 100점입니다. 이후 오차에 따라 초당 25점씩 감점하며 최저점은 20점입니다. 제한 시간 안에 멈추지 못하면 20점입니다. |

## 실행 환경

- Python 3.10 이상
- 최신 Google Chrome 또는 Chromium 기반 브라우저 권장
- 마이크 또는 마이크가 포함된 헤드셋
- 3인 플레이 시 같은 로컬 네트워크에 연결된 PC 3대 권장

ES Module과 마이크 권한을 사용하므로 `index.html`을 직접 열지 말고 반드시 HTTP 서버로 실행해야 합니다.

## 빠른 시작

### 1. 저장소 내려받기

```powershell
git clone https://github.com/1234jienf/Chop-Chop-Kitchen.git
cd Chop-Chop-Kitchen
```

### 2. 의존성 설치

```powershell
python -m pip install fastapi "uvicorn[standard]"
```

### 3. 웹 서버 실행

```powershell
python -m http.server 8080
```

브라우저에서 <http://localhost:8080>으로 접속합니다.

### 4. 멀티플레이 서버 실행

새 PowerShell 창을 프로젝트 루트에서 열고 실행합니다.

```powershell
python -m uvicorn py.multiplayer_api:app --host 0.0.0.0 --port 8001
```

클라이언트는 접속 중인 웹 페이지의 호스트를 기준으로 `ws://호스트:8001/ws`에 연결합니다. 같은 PC에서는 기본적으로 `ws://localhost:8001/ws`가 사용됩니다.

다른 PC에서는 다음 주소로 웹 게임에 접속합니다.

```text
http://웹 서버 PC의 IP 주소:8080
```

Windows 방화벽에서 TCP 8080번과 8001번 포트의 인바운드 연결을 허용해야 할 수 있습니다. 멀티플레이 방과 진행 상태는 메모리에만 보관되므로 서버를 재시작하면 초기화됩니다.

## AI 손님 리뷰 사용하기

AI 리뷰는 선택 기능입니다. 사용하지 않거나 API 요청이 실패해도 점수와 매출 계산은 그대로 동작하며 클라이언트의 기본 리뷰가 표시됩니다.

1. 환경 파일을 복사합니다.

```powershell
Copy-Item .env.example .env
```

2. `.env`의 값을 실제 OpenAI API 키로 교체합니다.

```dotenv
OPENAI_API_KEY=your-api-key
```

3. 별도 PowerShell 창에서 리뷰 서버를 실행합니다.

```powershell
python -m uvicorn py.review_server:app --host 127.0.0.1 --port 8000
```

리뷰 API는 `http://127.0.0.1:8000/review`에서 동작합니다. API 키를 브라우저 코드에 넣지 마세요. `.env`는 Git 추적 대상에서 제외되어 있습니다.

## 마이크 사용 시 주의사항

- 주소창 왼쪽의 사이트 권한에서 마이크를 허용해야 합니다.
- 주변 소음이 적은 곳에서 헤드셋 마이크를 사용하면 인식이 안정적입니다.
- `localhost`에서는 마이크를 사용할 수 있지만 다른 PC가 사설 IP의 HTTP 주소로 접속하면 브라우저 보안 정책에 의해 마이크가 제한될 수 있습니다.
- 외부 배포 시에는 HTTPS 웹 호스팅과 보안 WebSocket인 WSS 사용을 권장합니다.
- Chrome의 Web Speech API 지원 여부와 운영체제의 입력 장치 설정에 따라 음성 인식 결과가 달라질 수 있습니다.

## 주요 설계 원칙

- 게임 점수, 별점과 매출은 `src/dayresult.js`의 고정 공식으로 계산합니다.
- AI는 이미 계산된 결과를 리뷰 문장으로 바꾸는 역할만 수행합니다.
- 멀티플레이 서버가 현재 차례와 공정 결과를 관리합니다.
- 현재 담당자만 공정을 제출할 수 있고 다른 플레이어는 활동 데이터를 관전합니다.
- 브라우저에 OpenAI API 키를 노출하지 않습니다.

## 현재 구현 상태와 제한사항

- 공개 웹 플레이 URL과 APK는 제공되지 않으며 현재는 로컬 웹 서버로 실행합니다.
- 멀티플레이 상태는 영구 저장되지 않습니다.
- 외부 환경의 완전한 온라인 멀티플레이를 위해서는 HTTPS 정적 호스팅, 별도 WebSocket 서버 배포와 WSS 설정이 필요합니다.
- `py/api.py`는 Whisper 실험 코드이며 기본 게임 실행에는 필요하지 않습니다.
- 현재 `src/state.js`는 `src/data.js`에서 `createStarterMenu`를 가져오지만 해당 export가 정의되어 있지 않습니다. 이 불일치를 해결하기 전에는 브라우저가 `state.js` 모듈을 불러오지 못할 수 있습니다.
