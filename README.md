# Chop-Chop-Kitchen

5일 게임잼/해커톤을 위한 **빌드 도구 없는 웹 데모 골격**입니다. 현재 목표는 완성 게임이 아니라 라운드 흐름과 마이크 기술 검증을 빠르게 시작하는 것입니다.

## 실행

ES Module과 마이크 권한 때문에 HTML 파일을 직접 열지 말고 로컬 서버로 실행하세요.

```powershell
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`으로 접속합니다. GitHub Pages에는 저장소 루트를 그대로 배포할 수 있습니다.

## 현재 포함된 것

- 시작 추천 4코스와 12개 공정 데이터
- 셰프 A → B → C 순서의 릴레이 상태 전환
- 성공/실수 테스트 버튼, 고정 공식 기반 점수·별점·매출
- 실제 마이크 권한 요청과 실시간 볼륨 미터
- 점수 결과를 문장으로 포장하는 로컬 리뷰(추후 AI API 교체 지점)
- 모바일 대응 기본 UI

## 폴더 구조와 추천 담당

```text
index.html       화면 뼈대
styles.css       공용 스타일/조리 장면
src/
  data.js        레시피·손님·소리 패턴 데이터
  state.js       라운드/릴레이/채점 규칙
  audio.js       마이크 입력과 볼륨 분석
  main.js        화면 렌더링과 이벤트 연결
docs/
  architecture.md  5일간 지킬 범위와 API 경계
```

- 1명: `audio.js`에서 소리 특징 추출·분류기
- 1명: `state.js`, `data.js`에서 게임 규칙·채점
- 1명: `index.html`, `styles.css`, `main.js`에서 화면·연출

## 중요한 원칙

브라우저에서 OpenAI API 키를 직접 사용하지 않습니다. Day 4에 서버리스 함수가 준비되면, 클라이언트는 고정 공식으로 계산한 결과만 보내고 AI는 리뷰 문장만 생성하도록 연결하세요. 음성 분류가 Day 3까지 안정화되지 않으면 현재 테스트 버튼을 실제 플레이 입력으로 꾸며 데모 경로를 보존합니다.
