# **Chop-Chop Kitchen**

직접 학습한 음성 인식 AI를 활용해 세 명의 셰프가 목소리로 요리 공정을 이어 가는 3인 협동 브라우저 요리 게임

Chop-Chop Kitchen은 플레이어가 마이크에 조리 소리를 내며 4코스 요리를 완성하는 협동 게임입니다. 세 명의 플레이어가 한 명씩 돌아가며 자르기, 끓이기, 굽기, 섞기, 뿌리기·붓기 등의 공정을 수행하고, 각 공정의 정확도에 따라 코스 점수와 매출이 결정됩니다.

조리 음성은 프로젝트에서 직접 학습한 Teachable Machine Audio 모델로 분류합니다. 브라우저에서 TensorFlow.js와 Speech Commands를 이용해 탁, 찹, 사각, 스윽, 후, 띵 등의 소리를 인식하며, 오븐 정지와 일부 대본 입력에는 Web Speech API를 함께 사용합니다. 하루가 끝나면 OpenAI의 GPT-4o mini가 플레이 결과를 바탕으로 손님의 미식 리뷰를 생성합니다. AI 리뷰를 사용할 수 없을 때는 게임에 내장된 리뷰가 대신 표시됩니다.

### **게임 진행 단계**

1. **오프닝**: 첫 화면에서 게임 시작을 누릅니다.
2. **식당 입장**: 현재 일차와 식당 외관을 확인하고 식당 문을 눌러 입장합니다.
3. **영업 준비**: 셰프 준비하기를 눌러 팀 설정 화면으로 이동합니다.
4. **팀 설정**: 혼자 체험하거나 3인 멀티플레이 방에 참가한 뒤, 플레이어 카드를 드래그해 조리 순서를 정하고 준비하고 시작하기를 누릅니다.
5. **주방 맵**: 오늘의 손님과 4코스 메뉴, 전체 조리 순서를 확인합니다. 현재 차례의 셰프가 표시된 조리 스테이션을 선택합니다.
6. **조리 공정 수행**: 현재 차례인 플레이어가 자르기, 끓이기, 굽기, 섞기, 뿌리기·붓기 등의 공정을 수행합니다. 공정이 끝나면 다시 주방 맵으로 돌아가 다음 스테이션으로 이동합니다.
7. **코스 완성**: 한 코스의 모든 공정을 마치면 완성된 요리 화면이 나타납니다. 다음 요리 시작하기를 눌러 에피타이저, 스타터, 메인, 디저트 순서로 조리를 이어 갑니다.
8. **손님 심사 및 정산**: 네 코스를 모두 완성하면 손님의 코스별 리뷰, 점수, 별점, 손님 취향 보너스와 매출이 영수증 형태로 표시됩니다.
9. **다음 일차**: 정산하고 다음 날을 누르면 당일 매출이 누적되고 새로운 손님이 등장합니다. 이후 식당 입장과 팀 설정 과정을 거쳐 다음 날 영업을 시작합니다.

### **메뉴 도감**

| **구분** | **쉬움** | **보통** | **어려움** |
| --- | --- | --- | --- |
| 에피타이저 | 과카몰리 | 브루스케타 | 카프레제 타르타르 |
| 스타터 | 클램 차우더 | 미네스트로네, 프렌치 어니언 수프 | 크림 오브 머쉬룸 |
| 메인 | 로스트 치킨, 미트볼 파스타 | 스테이크 플레이트 | 안심 웰링턴 |
| 디저트 | 애플 타르트 | 크림 브륄레, 블루베리 크럼블 케이크 | 초콜릿 라바케이크 |

매일 새로운 손님이 무작위로 등장하며, 손님의 선호 공정과 해당 일차의 난이도를 기준으로 에피타이저·스타터·메인·디저트가 하나씩 선정됩니다. 같은 조건의 레시피가 여러 개라면 그중 하나가 무작위로 선택됩니다. 난이도는 1일 차 쉬움, 2~3일 차 보통, 4일 차부터 어려움으로 적용되며 다음 날이 되면 손님과 4코스 메뉴가 모두 새로 선정됩니다.

## **게임 실행 방법**

#### **혼자 체험하기**

1. 공개 플레이 페이지(https://1234jienf.github.io/Chop-Chop-Kitchen/)를 Chrome에서 엽니다.
2. 게임 시작 → 식당 문 → 셰프 준비하기 순서로 이동합니다.
3. 멀티 서버에 접속하지 않고 준비하고 시작하기를 누릅니다.

이 방식은 한 브라우저에서 세 셰프의 차례를 번갈아 조작하는 오프라인 체험 모드입니다.

#### **3인 멀티플레이**

1. 세 명 모두 공개 플레이 페이지(https://1234jienf.github.io/Chop-Chop-Kitchen/)에 접속합니다.
2. 셰프 준비하기 화면에서 운영진에게 전달받은 서버 주소를 **멀티 및 GPT 서버 주소** 칸에 붙여 넣습니다.
3. 같은 방 코드(default: KITCHEN)를 입력하고 각자의 이름(default: CHIEF)으로 방 참가를 누릅니다.
4. 세 명이 입장하면 플레이어 카드를 드래그해 조리 순서를 정합니다.
5. 준비하고 시작하기를 누르면 게임이 시작됩니다.

서버 주소는 세 플레이어가 모두 동일하게 입력해야 합니다.

게임 중에는 현재 차례인 플레이어만 조리 입력을 사용할 수 있습니다. 나머지 두 플레이어는 같은 조리 화면과 진행 상태를 실시간으로 확인합니다.

## **게임 방법**

### **목표**

세 명의 플레이어가 정해진 차례에 맞춰 에피타이저, 스타터, 메인, 디저트로 구성된 4코스의 모든 조리 공정을 완료하는 것이 목표입니다.

각 공정을 정확하게 수행해 높은 코스 점수와 별점을 얻고 매출을 올려야 합니다. 손님이 선호하는 종류의 공정을 모두 70점 이상으로 완료하면 최종 점수 5점과 매출 100G를 추가로 받을 수 있습니다.

### **조작 방법**

조리 화면에서 마이크 켜기를 누르고 브라우저의 마이크 권한을 허용합니다.

| **조리 공정** | **조작 방법** |
| --- | --- |
| 자르기 | 화면에 표시되는 리듬에 맞춰 탁, 찹, 사각, 스윽 등의 소리를 냅니다. |
| 끓이기 | 후우 소리를 내어 끓이기 진행도를 채웁니다. |
| 일반 굽기 | 후우 소리로 화력을 올리고, 입을 다물어 화력을 낮추면서 목표 화력 구간을 유지합니다. |
| 오븐 굽기 | 타이머와 목표 지점을 확인한 뒤 알맞은 순간에 띵 소리를 내어 오븐을 멈춥니다. |
| 섞기 | 화면에 제시된 대본을 읽습니다. 목소리의 음량과 인식 결과가 움직임과 점수에 반영됩니다. |
| 뿌리기·붓기 | 화면에 표시된 목표 음정을 내고 정해진 시간 동안 유지합니다. |

마이크 입력을 사용할 수 없는 환경에서는 화면의 성공 입력, 실수 입력 및 테스트용 버튼으로 진행할 수 있습니다.

### **점수와 보상**

- 각 공정은 20~100점으로 평가됩니다.
- 코스 점수는 해당 코스에 포함된 공정 점수의 평균입니다.
- 최종 점수는 코스 점수의 평균에 손님 취향 보너스를 더해 계산하며 최대 100점입니다.
- 별점은 최종 점수 20점당 1개로 계산하며 최소 1개, 최대 5개입니다.
- 각 코스의 매출은 75 + 코스 점수 × 2입니다.
- 손님 취향 조건을 달성하면 최종 점수 +5, 하루 매출 +100G를 받습니다.
- 누적 자금이 3,000G 이상이 되면 식당 등급이 1성에서 2성으로 올라갑니다.

모든 코스를 완료하면 위 결과가 오늘의 심사 영수증 형태로 표시됩니다. 영수증에서는 코스별 점수·리뷰·매출, 손님 요청 달성 여부와 보너스, 최종 점수와 별점, 하루 총매출을 한 번에 확인할 수 있습니다. GPT-4o mini는 계산이 끝난 결과를 자연스러운 미식 리뷰로 표현하는 역할만 하며 게임의 점수와 매출에는 영향을 주지 않습니다.

### **종료 조건**

한 게임의 플레이 범위는 4코스의 모든 공정을 완료하고 손님 리뷰와 정산 결과를 확인할 때까지입니다.

정산 화면에서 정산하고 다음 날을 누르면 획득한 매출이 누적되고 새로운 손님과 함께 다음 날을 시작합니다. 현재 버전에는 별도의 최종 엔딩 조건이 없으므로 플레이어가 정산을 마치고 게임을 종료하거나 다음 날 플레이를 계속할 수 있습니다.
